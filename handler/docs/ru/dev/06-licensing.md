# Лицензирование

## Сам проект — MIT

Код обработчика распространяется по лицензии **MIT** — текст в [LICENSE.txt](../../LICENSE.txt), `Copyright (c) 2026 Sophron Ragozin`: использовать, модифицировать и распространять можно свободно при сохранении уведомления о copyright.

## Moza SDK — не MIT

Moza SDK (нативные `MOZA_API_C.dll` / `MOZA_SDK.dll`, C#-обёртка `MOZA_API_CSharp.dll` и утилиты в `sdk/`) — **отдельная лицензия Moza Racing**, а не MIT: <https://mozaracing.com/pages/sdk>. В папке `sdk/Licenses/` лежат лицензии компонентов, входящих в состав SDK (OpenSSL, libcoap, nanaCbor).

**Что это значит:**

- **для пользователей** — сам проект свободен (MIT), но SDK распространяется по правилам Moza Racing; его нельзя считать частью этого репозитория под MIT. Каждый пользователь скачивает SDK с сайта Moza сам и принимает его лицензию;
- **для контрибьюторов** — присылать можно только код проекта (MIT). Правила SDK (редистрибуцию, изменение, включение бинарников в свои сборки) определяет Moza Racing, а не эта лицензия: перед любой операцией с SDK сверяйтесь с его лицензией.
