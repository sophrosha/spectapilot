# <font color="FF6600">Spect</font>APilot (<font color="FF6600">Spectator Auto</font>Pilot)

## Идея

Воссоздать реализацию передачи телеметрии движения руля из BeamNG в руль прямого привода.

## Как реализовать

Для данной задумки важны три вещи

1. Мод - получает телеметрию руля, блокирует систему вождения через руль позволяя работать рулю как визуализатор а не физический источник передачи данных в игру.

2. Обработчик - получает по открытому порту протокола UDP данные из игры в реальном времени. Дальше обрабатывает данные значения и переводит уже данные в руль посредством библиотеки которая совмещена с DD.

3. Эмулятор - так как отсуствует руль, необходимо видеть наклоны и повороты руля для отладки.

## Мод

### Описание

Передача игровой телеметрии руля, и отправка по udp протоколу в обработчик.

### Стек

- Язык: Lua

- Библиотеки: LuaSocket, стандартные библиотеки игры

### Реализация

#### Интерфейс игры

Настройка айпи и порта сервера обработчика, так же включение и выключение режима

#### Внутри кода

Инициализация подключения по веденному айпи и порту, захват необходимых переменных и передача их в формате json, так же блокировка получения данных руля из игры.

## Обработчик

### Описание

Обрабатывает данные которые идут по открытому соединению через порт в руль

### Стек

- Язык python

- Библиотеки: socket, MozaSDK, AsyncIO, mathlib, random, json, tk

- Вызов: запуск отдельно с окном настройки и ожиданием подключения

### Реализация

#### Интерфейс

Указывание собственных настроек порта, ограничения максимального угла руля, тестирование посредством заготовленных данных в отдельном файле, настройка режима "Возьми меня"

#### Внутри

По открытому UDP порту приходят данные в формате схожего с json, после чего обрабатываются значения наклона, усиление и прочих данных. Обработанные данные дальше поступают к рулю по фирменной библиотеке руля.

  

Предусмотрены системы безопасности, чтобы руль не смог из одной стороны провернуться сразу в другую сторону дрожа.

#### "Возьми меня"

Данный режим предполагает ограничение радиуса угла руля до 170 градусов, и безопасное удержание руля в руке. Это не означает управление человеком, а наоборот дает человеку почувствовать повороты руля которым управляет автопилот. При какой либо силе руля которая тоже будет приниматься руль просто отключится на 20 секунд так как при сопротивлении может испортится механизм
