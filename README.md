## What is it
A project that transmits steering wheel telemetry from `BeamNG.drive` to a real physical steering wheel with `FFB` support. 

The goal is to experience an autopilot system right from your home, using just a standard `DD`/`FFB` supported steering wheel.

## Key Features
- Full autopilot visualization without leaving your home
- Customizable settings and configurations
- Adjustable `FFB`, wheel centering force, and steering angle locks
